## Wireframe Guidelines

- **Grayscale only** (no colors, no branding)
- **Structure and layout** (boxes, labels, buttons)
- **All key states** (empty, populated, loading, error)
- **Device profile noted** (desktop, tablet, mobile)
- **Format:** Markdown with ASCII art or Mermaid, or simple HTML file
- **Focus:** Information architecture and workflow, not visual design

## Notes

These are **structural wireframes** for Phase 0 planning. They inform:
- Data requirements
- User workflows
- State management needs
- Component identification for UI kit

**Final visual design** is applied later in the Design Pass (Part 4) and must not alter the planned functionality.
